# **App Name**: HealthWise AI

## Core Features:

- Symptom Input: Collect user-provided symptoms through an interactive UI.
- Data Preprocessing: Clean and prepare symptom data for machine learning models.
- ML Model Prediction: Utilize decision tree or naive Bayes models to predict possible health issues based on symptoms.  The AI tool will reason about the symtoms.
- Accuracy Check: Evaluate the accuracy of the ML model's predictions.
- Result Display: Display the predicted health issues and their likelihood to the user.

## Style Guidelines:

- Primary color: Light green (#A7D1AB) for a sense of health and well-being.
- Secondary color: Soft gray (#E5E5E5) for a clean and neutral background.
- Accent color: Teal (#008080) to highlight important information and calls to action.
- Body font: 'Roboto' for readability and a modern feel.
- Headline font: 'Montserrat' for clear and engaging titles.
- Use simple and clear icons related to health and symptoms.
- Single-column layout for easy navigation on mobile devices.
- Subtle animations for feedback on user interactions.
